# 🧭 정책 탐색기 (Youth Policy Finder)

> **온통청년(youthcenter.go.kr) 오픈API 기반 맞춤형 청년정책 자격 판정기**  
> 대상 사용자: **대구에 사는 30대 취업준비생**  
> 핵심 기능: **나이·거주지·취업상태·학력을 입력하면 나에게 해당되는 정책만 골라서 보여주는 실시간 자격 판정기**

---

## 🌟 주요 기능

1. **조건 입력 폼**
   - **나이**: 만 18세 ~ 39세 슬라이더 및 빠른 선택 (기본: 만 32세, 30대 청년)
   - **거주지**: 대구광역시 (구/군 세부 설정) 및 전국 시·도 선택
   - **취업 상태**: 취업준비생, 미취업자, 단기근로자, 재직자, 창업가, 대학생
   - **최종 학력**: 대졸 이상, 대학(교) 재학, 고졸 이하, 대학원 이상, 제한없음
   - **대구 30대 취준생 원클릭 프리셋**: 버튼 하나로 맞춤 조건 즉시 적용
   - **자연어 간편 입력기**: *"대구 사는 31살 대졸 취준생"* 입력 시 조건 자동 파싱 및 설정 (외부 연동 축소 규칙)
   - **조건 자동 저장**: 브라우저 `localStorage`를 통해 재방문 시에도 직전 조건 유지

2. **조건에 맞는 정책 카드 목록**
   - **일치 항목 배지**: 연령·거주지·취업상태·학력 4대 조건별 일치 여부 실시간 표시
   - **적합도 점수 & 판정율**: 100% 완전 일치(신청 적격), 75% 적합 등 점수화
   - **D-Day 계산 배지**: 상시 접수, D-7 이내 마감 임박 강조(붉은색 펄스), 오늘 마감, 마감됨 구분
   - **다양한 필터 & 정렬**: 분야별 탭(일자리, 주거, 교육, 복지문화, 참여권리), 100% 부합 정책만 보기 토글, 적합도순/마감임박순/최신순 정렬
   - **반응형 그리드**: 모바일(360px) 1열, 태블릿 2열, PC(1440px) 3열 완벽 대응
   - **상태 처리**: 로딩 스켈레톤, 빈 결과(조건 완화 안내), 오류(재시도 버튼) 3대 상태 완벽 지원

3. **정책 상세 모달 & 신청 링크**
   - 정책 개요, 상세 지원 내용, 세부 자격 요건
   - **나의 조건 vs 정책 요건 대조 테이블**: 4개 항목 1:1 비교 검증
   - **원스톱 신청 링크**: 해당 정책 공식 신청 페이지(없을 시 온통청년 통합검색으로 자동 대체)
   - **캘린더 일정(.ics) 다운로드**: 마감일 D-3 알림이 포함된 캘린더 파일 다운로드 (외부 연동 축소 규칙)
   - **지원 내용 복사**: 클립보드 원클릭 복사
   - **외부 공공 지도 및 포털 연계**: 대구 청년센터 지도 위치 검색, 마이홈 청년주거 포털 검색 링크 제공

4. **안전한 폴백 & API 키 보호**
   - 브라우저 코드에서 API 키를 절대 참조하지 않으며, `/api/policies.ts` 서버리스 함수에서만 호출
   - 신규 규격(A) → 구 규격(B) 순서로 시도하며, 실패 시 20건의 검증된 대구 청년정책 샘플 데이터로 자동 폴백

## 🚀 1. 로컬 개발 환경 실행 방법

```bash
# 1. 패키지 설치
npm install

# 2. (선택) 온통청년 API 키 설정
# .env.local 파일에 발급받은 API 키를 입력합니다.
# 키가 없어도 자동으로 20건의 풍부한 샘플 데이터로 즉시 동작합니다.
echo "YOUTH_API_KEY=발급받은_온통청년_API키" > .env.local

# 3. 개발 서버 시작 (포트 3000)
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속하여 테스트합니다.

## ☁️ 2. Vercel에서 GitHub 저장소 Import 및 배포

1. [Vercel 대시보드](https://vercel.com/dashboard)에 로그인합니다.
2. **Add New...** → **Project**를 클릭합니다.
3. GitHub 계정을 연동하고 본 저장소를 찾아 **Import**를 누릅니다.
4. **Framework Preset**이 `Vite`로 자동 감지되는지 확인합니다.
5. **Root Directory**는 기본값(`./`)으로 유지합니다.

---

## 🔑 3. Vercel 환경변수(YOUTH_API_KEY) 등록

1. Vercel 프로젝트 생성 화면 또는 프로젝트 설정(**Settings → Environment Variables**)으로 이동합니다.
2. 아래와 같이 환경변수를 추가합니다:
   - **Key**: `YOUTH_API_KEY`
   - **Value**: 온통청년(youthcenter.go.kr)에서 발급받은 오픈API 인증키
   - **Target**: Production, Preview, Development 전체 체크
3. **Save**를 클릭하여 저장합니다.

---

## 🔄 4. 재배포(Redeploy) 방법

환경변수를 등록한 후 반드시 새 빌드를 배포해야 서버리스 함수에 환경변수가 반영됩니다.

1. Vercel 대시보드의 **Deployments** 탭으로 이동합니다.
2. 최상단의 최신 배포 항목 우측의 점 세 개(`...`) 메뉴를 클릭합니다.
3. **Redeploy**를 선택합니다.
4. "Use existing Build Cache" 체크를 해제하고 **Redeploy** 버튼을 누릅니다.

---

## ⚠️ 5. 샘플 배너가 사라지지 않을 때 점검 항목

온통청년 API 키를 등록했음에도 상단에 **"샘플 데이터로 표시 중"** 배너가 유지되는 경우 다음 사항들을 점검하세요:

1. **Vercel 환경변수 명칭 확인**
   - 환경변수 이름이 정확히 `YOUTH_API_KEY`인지 확인합니다 (오탈자, 소문자 주의).
2. **배포 시점 확인 (Redeploy 필수)**
   - Vercel에서 환경변수를 추가한 후 **Redeploy**를 실행하지 않으면 이전 빌드 컨테이너에는 키가 전달되지 않습니다.
3. **온통청년 오픈API 발급 승인 여부**
   - 온통청년(youthcenter.go.kr) 오픈API 관리자 페이지에서 신청한 키가 '승인 완료' 상태인지 확인합니다.
4. **온통청년 API 서버 트래픽/점검 상태**
   - 온통청년 공공데이터 서버는 야간 정기 점검 또는 트래픽 과부하 시 일시적으로 응답이 지연되거나 HTML 에러 페이지를 반환할 수 있습니다.
   - 이때 우리 앱은 오류로 중단되지 않고 **샘플 데이터로 자동 폴백**하여 사용자 경험을 보호합니다.
5. **Vercel Functions 로그 확인**
   - Vercel 대시보드의 **Logs** 메뉴에서 `/api/policies` 호출 시 출력되는 로그(`[policies-api]`)를 확인하면 API 응답 상태를 즉시 대조할 수 있습니다.
